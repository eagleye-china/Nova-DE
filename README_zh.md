## 🤔 为什么选择 nova-de？

- 🚀 **极致性能**：基于原生 PySide6 和 QML，拒绝笨重的 WebView。
- 🎨 **顶级颜值**：原生暗黑模式，丝滑动画，像素级布局。
- 🧠 **AI 原生**：开箱即用的 OpenAI / DeepSeek 协议支持。

## 📦 安装

```bash
pip install nova-de
```
